# Source of Truth Protocol

## Authority order

1. Signed law, regulation, licence, contract, appointment, or official record
2. Direct written statement from the accountable organization
3. Named primary public source
4. Documented participant statement
5. Planning model or working assumption
6. Informal inference

Higher-ranked evidence supersedes lower-ranked evidence for current decisions. Superseded statements remain in the historical register.

## Required fields for every material claim

- Claim ID
- Statement
- Classification
- Source
- Source date
- Source owner
- Geography
- Commercial lane
- Confidence
- Current status
- Validation owner
- Next action
- Last reviewed

## Relationship provenance

Introductions and access must be recorded without implying ownership. Current reported chain:

`Marine Foundation network -> Major Dream Williams -> Brother Ling -> China supplier discussions -> Diallo / Mauritania market hypothesis`

This chain is historical provenance, not an automatic allocation of economics or authority.

## Precedence test

If new evidence conflicts with an existing claim:

1. Record the new source.
2. Identify the conflict.
3. Compare authority and recency.
4. Record the resolution.
5. Preserve the earlier statement as historical truth.
6. Update all active documents and product surfaces.
7. Add a validation rule where feasible.
